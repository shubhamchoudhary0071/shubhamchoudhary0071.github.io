Privacy Policy

Gyaan Studio Uploader (the "App") — last updated 18 November 2026. Home page: Gyaan Studio Uploader.

1. Who this applies to

The App is a personal automation tool operated by Shubham Choudhary (the "Owner") for the Owner's own YouTube channels. It is not offered to the public and the Owner is its only user.

2. Google user data the App accesses

When the Owner signs in with Google and approves access, the App can use the following YouTube permissions on the Owner's own account:

  • youtube.upload — upload videos and set their title, description, tags and schedule.
  • youtube — create playlists and add videos to them.
  • youtube.readonly — read channel information and statistics (subscribers, views).

3. How the data is used

Data is used only to publish and organise the Owner's videos and to show the Owner their own channel statistics. It is not used for advertising, is not sold, and is not shared with or transferred to any third party. No human reads the data other than the Owner.

4. Storage and security

The OAuth refresh/access tokens are stored as files on the Owner's own private computer/server with restricted file permissions. The App does not run any public server or database and collects no data from visitors. This website is static and does not use cookies or analytics.

5. Retention and deletion

Tokens are kept only while the automation is in use. The Owner can revoke the App's access at any time at myaccount.google.com/permissions, and can delete the stored tokens, which removes all Google user data held by the App.

6. Google API Services User Data Policy

The App's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. The App also uses YouTube API Services and is bound by the YouTube Terms of Service and the Google Privacy Policy.

This policy may be updated; the date above shows the latest version.
