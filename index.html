Gyaan Studio Uploader

Gyaan Studio Uploader is a small, private automation tool used by one person, Shubham Choudhary, to publish and schedule short videos on his own YouTube channels: 60 Second Gyaan (podcast highlight clips with credit to the original creators) and Karm Gyaan (Bhagavad Gita explainer Shorts).

What the app does

  • Uploads video files that the owner has prepared, with a title, description, tags and a scheduled publish time.
  • Creates and fills playlists on the owner's channels (for example, one playlist per Gita chapter series).
  • Reads basic channel statistics (subscriber count, views) so the owner can track progress.

Who uses it

Only the app owner. The app is not offered to the public, has no sign-up, and never accesses anyone else's Google account. It runs on the owner's own computer and uses OAuth 2.0 with the owner's own Google account.

Google API Services

The app uses the YouTube Data API v3. Its use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube API Services is also subject to the YouTube Terms of Service and the Google Privacy Policy.
